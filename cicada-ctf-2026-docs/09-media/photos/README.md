# Photos Directory Structure

This folder stores all compressed (`≤ 500 KB`, `1920x1080`) event photographs and charts organized by **lifecycle phase** and **responsible organizing team**:

```text
/09-media/photos
├── planning/
│   ├── documentation/
│   ├── logistics/
│   ├── pr-and-design/
│   ├── sponsorship/
│   ├── outreach/
│   └── development/
├── preparation/
│   ├── documentation/
│   ├── logistics/
│   ├── pr-and-design/
│   ├── sponsorship/
│   ├── outreach/
│   └── development/
├── event-days/
│   ├── documentation/
│   ├── logistics/
│   ├── pr-and-design/
│   ├── sponsorship/
│   ├── outreach/
│   └── development/
└── post-event/
    ├── documentation/
    ├── logistics/
    ├── pr-and-design/
    ├── sponsorship/
    ├── outreach/
    └── development/
```

Refer to [../photo-index.md](../photo-index.md) for the exact filenames required in each subfolder and [../image-guidelines.md](../image-guidelines.md) for naming, sizing, and consent rules.
